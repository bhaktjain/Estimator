**Gaps to add or clarify:**

1. **Permits** – Add MISC-01 Permits and Fees (master pricing).
2. **Waste removal** – Add MISC-03 Waste Removal (master pricing).
3. **Structural & roof** – Add allowance or sub quote for foundation, floor framing, roof (removal + new per D-01/D-02 and S-2.1); no master code.
4. **Building A demo** – Concrete walk removal and any Building A roof removal: either add small demo allowance or fold into structural/roof allowance.
5. **Roof insulation** – Add if in contract (no master code; allowance or sub).
6. **Sprinklers** – Add only if contract includes (MISC-19 or sub).
7. **Second bath/kitchen** – If Building B has its own full kitchen and bath, add second set of plumbing (and possibly electrical) lines.
